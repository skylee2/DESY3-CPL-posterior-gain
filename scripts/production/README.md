# Historical production code

This directory contains verified scripts used during manuscript development.
Historical internal version strings and old manuscript filenames in comments or
docstrings are provenance labels, not references to the authoritative
manuscript. The release's authoritative target is
`paper1_Y3_submission_finaljournal_v3.tex`.

`bs_brs_bootstrap_v072.py` generates the BS-to-BRS bootstrap adopted by v3.
The older v07.1 script is intentionally excluded. The `d3_stage1` modules are
retained because they generate the D3 point, robustness, public-chain, and
bootstrap validation artifacts used by v3.
